# Крестики-нолики

Учебный проект для практической работы по CI/CD. Игра написана на Python по TDD.

## Что умеет игра

- ходы по очереди, первым ходит X;
- проверка победы по строкам, столбцам и диагоналям;
- ничья, если поле заполнено и победителя нет;
- `current_player()` показывает, чей ход, после победы возвращает `None`;
- ошибка при ходе в занятую клетку, за пределы поля или после конца игры.

## Запуск тестов

    pip install -r requirements.txt
    python -m pytest -v

## CI/CD

- `.github/workflows/main.yml` запускает тесты при каждом push в любую ветку и при pull request в main;
- в main нельзя отправить код напрямую, только через pull request, и он сливается автоматически, когда тесты прошли;
- `.github/workflows/docs.yml` при каждом обновлении main собирает документацию из docstrings (pdoc) и публикует её на GitHub Pages.

Документация: https://gordenator.github.io/ci-cd-tictactoe/
